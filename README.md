# Vinayak Yadav — Kubernetes / Linux / DevOps Portfolio

A one-page, GitHub Pages-ready portfolio with a Kubernetes/Linux operations aesthetic.

## Sections

- Hero / terminal status
- About
- Impact metrics
- Work experience
- Projects
- Skills
- Certifications
- Education
- Contact

## Run locally

No Node.js or build system is required.

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Deploy to GitHub Pages

1. Create a repository named `<your-github-username>.github.io`.
2. Copy these files into the repository.
3. Push to the `main` branch.
4. In GitHub: Settings → Pages → Source: GitHub Actions.
5. The included workflow will publish the site.

## Before publishing

Update the contact links and any project URLs you want to expose. The current version intentionally does not invent a GitHub profile URL because the supplied resume/LinkedIn materials did not establish one.

## Source note

Content was adapted from the supplied resume and LinkedIn profile. Where the two sources differ on historical employment dates, the site uses broader date labels rather than silently choosing one.
